FOLLOW THE DATA

数据走哪条路？

GPU × 8⇄NVLink Switch⇄GPU × 8 域内

同一台 DGX 内：第五代 NVLink 连接 GPU，整机聚合带宽 14.4 TB/s。与跨机网络速度不能直接按数字等同。

本机 GPU→ConnectX-8→IB / Ethernet 交换机

跨 DGX：ConnectX-8 经外部网络与另一台整机通信，每个接口最高 800 Gb/s。128 台需要规划交换机、光模块、线缆和拓扑。

数据集 / 存储⇄BlueField-3⇄主机与应用

CPU、主机内存、GPU HBM 和本地 SSD 各有用途；磁盘容量不能替代 GPU 显存。
